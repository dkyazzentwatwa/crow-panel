# Arduino libraries for the CrowPanel AIoT suite
#
# Every entry is COMPILE-VERIFIED against esp32:esp32@3.3.8 on the
# esp32:esp32:esp32p4 target at the version shown. Nothing is
# hardware-verified until it runs on the real CrowPanel (see
# docs/hardware-bringup-checklist.md). Install everything with
# scripts/install-libs.sh.
#
# Library                    Verified version   Used by
# -------------------------  -----------------  -----------------------------------------
# ArduinoJson                7.4.3              LoRa/Wi-Fi payloads and Project 16 bridge JSON
# RadioLib                   7.7.1              USE_LORA_DRIVER - SX1262; Elecrow's own
#                                               library choice in their Lesson13 example
# GFX Library for Arduino    1.6.6              USE_DISPLAY - Arduino_GFX: Adafruit-GFX-
#                                               style API + MIPI-DSI panel classes
#                                               (Arduino_ESP32DSIPanel). No LVGL in this
#                                               repo by design.
# U8g2                      2.36.19             Project 18 compact typography through
#                                               Arduino_GFX's native U8g2 font path
# SensorLib                  0.4.1              USE_DISPLAY - GT911 capacitive touch
# Adafruit PN532             1.3.4              USE_PN532_DRIVER (+ Adafruit BusIO)
# MFRC522                    1.4.12             USE_MFRC522_DRIVER
# RF24                       1.6.1              optional nRF24-style socket module
# NimBLE-Arduino             2.5.0              Cypher Flock ESP32 BLE aggregator
# TinyGPSPlus                1.0.3              USE_GPS_DRIVER - NMEA parsing for the
#                                               project 13 SurveyOps wardriver rows
# JPEGDEC                    1.8.4              Project 25 Inkwell EPUB cover thumbnails
#                                               (JPEG); was already installed locally but
#                                               previously missing from this list
# PNGdec                     1.1.6              Project 25 Inkwell EPUB cover thumbnails
#                                               (PNG)
# SmartRC-CC1101-Driver-Lib  2.5.7              USE_STARBEAM_RADIOS - CC1101 sub-GHz on
#                                               project 19; PINNED in install-libs.sh.
#                                               The registry now offers 3.0.2, a major
#                                               bump nothing here has compiled against.
#
# Both entries above gate rows in scripts/check-flag-matrix.sh (project 13 [gps] and
# [survey-hardware-gated]; project 19 [radios] and [full]). Those rows SKIP rather than
# FAIL when a library is absent, so leaving them out of this file meant a fresh clone
# silently skipped four rows and still exited 0.
#
# Most mock sketches need only the bundled core. Project 16 also uses
# ArduinoJson in mock mode so injected and UART events share one parser.
#
# Camera note: there is intentionally no camera library, and none is needed.
# esp32-camera does not ship for the ESP32-P4 - but the P4 does not use it.
# Core 3.3.8 already bundles and links the ESP-IDF camera stack for this target
# (esp_driver_cam / esp_driver_isp / esp_driver_jpeg / esp_driver_ppa), so the
# MIPI-CSI path is reachable from Arduino with no third-party dependency. Only
# the SC2336 sensor register table is hand-written, and it lives in
# shared/CrowPanelShared/Sc2336Sensor.cpp.
# See projects/02-cypher-vision-cam/TECHNICAL.md.
