# CrowPanel CreatorOps Board

Content operations board inspired by `techtiff-brain`.

V1 uses static mock pipeline data for ideas, drafts, filming, scheduled,
published, tasks, and channel status. It is a dashboard, not a publisher.

## Serial Commands

- `help` / `status` / `history`
- `pipeline`
- `idea`
- `draft`
- `channel`
- `task`

No posting, scheduling, sending, or external account mutation happens in v1.
