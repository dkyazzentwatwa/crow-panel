# CrowPanel Cypher Gamer Arcade

Large touch arcade launcher inspired by `cardputer-games`.

V1 includes a touch-friendly catalog and three playable demos: Pong, Snake, and
2048. It is offline and local-first.

## Serial Commands

- `help` / `status` / `history`
- `catalog`
- `play pong`
- `play snake`
- `play 2048`
- `score`

Touch selects the catalog tile when `USE_DISPLAY=1`; Serial remains the smoke
test path.
