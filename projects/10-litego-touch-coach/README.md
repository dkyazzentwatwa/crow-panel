# CrowPanel LiteGo Touch Coach

Arduino C++ 9x9 Go coach inspired by the `ai-go` PWA.

V1 supports legal mock play on a 9x9 board, captures, pass/reset, simple CPU
move selection, liberty/atari coaching text, and a rough area score estimate.

## Serial Commands

- `help` / `status` / `history`
- `play <x> <y>`
- `cpu`
- `pass`
- `reset`
- `score`
