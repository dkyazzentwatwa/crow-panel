# Vision Guard Tutorial

Goal: demonstrate kiosk behavior before camera driver work.

## Steps

1. Compile in mock mode.
2. Open Serial Monitor at 115200 baud.
3. Watch camera status print every few seconds.
4. Wait for a mock QR scan.
5. Show pass/fail inspection results.
6. Explain where the AI vision API stub would connect.

## Real Hardware Phase

Camera work should start from the official Elecrow Arduino camera example for this board. Do not invent a pin map.
